## ✨ Key Features

- **Autonomous Incubation**: Agents monitor social trends to generate lore, symbols, and tokenomics for new launches.
- **Rug-Pull Defense**: 100% audited smart contracts with LP (Liquidity Provider) tokens burned automatically upon launch.
- **Agent Thought Stream**: A live terminal showing the real-time "internal monologue" of AI agents as they optimize token performance.
- **Bonding Curve Logic**: Fair-launch mechanics ensure no team allocations or pre-mines.
- **Sentiment-Driven Governance**: Agents adjust burn rates and buy-back strategies based on community sentiment analysis.

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite, Tailwind CSS, Framer Motion (for animations).
- **Backend**: Node.js, Express, TSX.
- **Icons**: Lucide-React.
- **Web3**: Ethers.js (integrated for wallet connection).
- **Styling**: Custom "Cyber-BNB" dark theme.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/your-repo/four-meme-ai.git
   cd four-meme-ai
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   # Terminal 1: Start the AI Orchestrator (Backend)
   npm run server

   # Terminal 2: Start the Vite Frontend
   npm run dev
   ```

4. **Open the browser:**
   Navigate to `http://localhost:5173` to view the dashboard.
